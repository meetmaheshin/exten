# Welcome to Ailancers Code

Ailancers Code is an AI coding agent built into VS Code, with project-aware time tracking and team analytics. The agent can read your files, write new code, run commands, and review what it just did — all while logging your time to the right project.

## Quick start

1. **Sign in** with your Ailancers account (Google, email, or auto-detect from a logged-in browser tab)
2. **Pick a project** so your time and AI usage are attributed correctly
3. **Open the AI chat** in the left sidebar and ask it something

That's it. Tracking starts automatically once you're signed in.

## Useful commands

- `Ailancers: Open Chat` — sidebar AI panel
- `Ailancers: Select Project / Task` — change which project gets billed
- `Ailancers: Open Activity Dashboard` — see what's been tracked

Open the Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`) and type "Ailancers" to see all commands.
